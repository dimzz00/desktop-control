# kendali 0.2.0 — Terminal: Desain

**Tanggal:** 2026-10-31
**Status:** Disetujui (brainstorming)
**Milestone:** 0.2.0
**Induk:** `docs/superpowers/specs/2026-10-30-kendali-remote-control-design.md`

## 1. Tujuan

Menambahkan mode terminal: browser (Android/Linux/Windows) dapat membuka shell di host
melalui `kendali-term`, dengan auth token, idle timeout, dan pembatasan percobaan.

## 2. Keputusan spike 14.1

Tunnel TCP RustDesk **tidak tersedia di client Android** (menu tidak ada; `enable-tunnel`
hanya izin sisi yang dikontrol). Maka jalur utama terminal di Android adalah
**`bind: tailnet`** (port 47654 di alamat tailnet host). Client desktop tetap dapat
memakai tunnel ke `127.0.0.1:47654` (bind `localhost`).

## 3. Komponen

- `cmd/kendali-term/` — sidecar Go.
- `internal/terminal/` — PTY, sesi, auth, rate limit, idle.
- `internal/webterm/` — aset xterm.js disematkan (`go:embed`).
- Service `kendali-term.service` (Linux) / Windows service, berjalan sebagai pengguna
  login, autostart.
- `rc term` subperintah (status, token URL).

## 4. Perilaku

- Mendengarkan `bind:port` dari `rc.yaml` (default `localhost:47654`).
- Satu shell per koneksi, sebagai pengguna login, bukan root.
- Auth: token 32 byte, constant-time compare; batas 5 percobaan per IP per menit;
  lockout 15 menit setelah 10 kegagalan.
- Idle timeout 30m (dari `rc.yaml`).
- Sesi dibersihkan saat koneksi putus.
- Transport: WebSocket; protokol xterm.js (input/output/resize).
- Token dikirim di URL query pada koneksi pertama; kendali-term menetapkan cookie sesi
  HttpOnly sehingga refresh tidak perlu token lagi.

## 5. Ketergantungan

- PTY: `github.com/creack/pty` (Linux/macOS), ConPTY via `github.com/UserExistsError/conpty`
  (Windows). Disuntik lewat build tag per OS.
- Web: xterm.js + addon-fit disematkan sebagai berkas statis (go:embed).
- WebSocket: `nhooyr.io/websocket` (stdlib-friendly, context-aware).

## 6. Status dan token

- `rc status` menampilkan URL terminal:
  - `localhost`: `http://127.0.0.1:47654/?token=<token>` (petunjuk tunnel)
  - `tailnet`: `http://<tailnet-ip>:47654/?token=<token>`
- `rc token --rotate` mengganti token dan memutus sesi aktif.

## 7. Keamanan

- Bind default `localhost`; `bind: tailnet` memerlukan konfirmasi eksplisit (rc install
  menanyakan atau flag `--bind-tailnet`).
- Tidak ada port yang terbuka ke LAN/USB untuk terminal.
- Log tidak memuat token atau isi sesi.

## 8. Kriteria penerimaan (0.2.0)

5. Terminal terbuka dari browser Android/Linux/Windows lewat tailnet atau tunnel;
   token salah, percobaan berlebih, dan idle ditolak sesuai §4.

## 9. Di luar cakupan 0.2.0

- Upgrade/rollback (0.3.0).
- Relay (nanti).
- Akun/izin (nanti).
