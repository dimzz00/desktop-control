# kendali 0.1.0 — Fondasi dan Koneksi Layar: Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menghasilkan `rc` (CLI Go) dan installer Linux/Windows yang memasang RustDesk resmi versi terkunci, mengonfigurasinya, lalu mencetak alamat LAN/USB/tailnet yang siap dipakai client Android/Linux/Windows.

**Architecture:** RustDesk dipakai apa adanya sebagai binary resmi berpaket (tanpa patch, tanpa fork). Semua logika kita ada di modul Go `rc`: konfigurasi, unduh+verifikasi, instalasi idempoten, deteksi alamat, dan diagnostik. Installer shell/PowerShell hanya bootstrap tipis yang mengunduh tarball lalu mengeksekusi `rc install`, sehingga perilaku kedua OS berasal dari satu kode yang sama.

**Tech Stack:** Go ≥1.23 (stdlib + `gopkg.in/yaml.v3` saja), GoReleaser tidak dipakai (skrip rilis sendiri), GitHub Actions (`ubuntu-22.04`, `windows-latest`), RustDesk rilis resmi, Tailscale, systemd/dpkg di Linux, MSI + `sc` di Windows.

**Spec:** `docs/superpowers/specs/2026-10-30-kendali-remote-control-design.md`

## Global Constraints

- Nol patch pada RustDesk. Hanya binary/paket rilis resmi yang tercatat di `deps.lock`.
- RustDesk **tidak** ikut mesin upgrade kita; `deps.lock` hanya mengunci versi dan `rc doctor` melaporkan drift.
- Hanya koneksi IP langsung. Jangan mengaktifkan rendezvous publik.
- Terminal (0.2.0) tidak dibangun di rencana ini; `rc status` hanya mencetak "belum aktif".
- Port terminal default `47654`; bind default `localhost`; token 64 karakter hex.
- Skema konfigurasi: `config_version: 1`. Skema lebih baru → tolak dengan `ErrFutureSchema`.
- Versi aplikasi hanya dari berkas `VERSION`, disuntik via `-ldflags "-X main.version=<VERSION>"`.
- `rc.yaml` selalu ditulis atomik (tmp + rename) dengan mode `0600`.
- Setiap berkas Go memuat header lisensi AGPL-3.0 (dicek `scripts/license.sh`).
- Tidak ada `sleep` di tes. Tidak ada tes yang memerlukan internet nyata (semua lewat `httptest`/fake runner).
- Coverage total paket `internal/**` minimal 80%, kecuali `internal/platform/exec.go`.
- Pesan commit: Conventional Commits. Setiap task berakhir dengan commit.
- Setelah setiap perubahan kode: `codegraph sync -q`. Selesai bila `codegraph status` bersih.
- Jalur terpasang: Linux `/opt/kendali`, `/etc/kendali/rc.yaml`, `/var/log/kendali`; Windows `%ProgramData%\kendali\{releases,rc.yaml,logs}`.

## Review Focus

1. **Simpan konfigurasi terputus di tengah** — pengguna kehilangan token/password karena `rc.yaml` tertulis separuh. Harapan: selalu atomik, berkas lama utuh sampai tulisan baru selesai.
2. **Mesin dengan antarmuka virtual** (`docker0`, `virbr0`, `veth*`, `tailscale0`) — `rc status` menampilkan alamat yang tidak bisa dipakai client. Harapan: antarmuka virtual diabaikan, tailnet dilabeli benar.
3. **Instalasi dua kali atau bersamaan** — paket terpasang ulang, konfigurasi tertimpa, atau mesin tertinggal setengah terpasang. Harapan: idempoten, aman dijalankan ulang, perubahan state hanya setelah verifikasi berhasil.
4. **RustDesk sudah ada dengan versi berbeda / dipasang orang lain** — tertimpa atau terhapus tanpa izin. Harapan: menolak dengan pesan jelas, dan uninstall hanya menghapus milik kita.
5. **Tailscale belum login, atau ada antarmuka `100.x` yang bukan tailnet** — alamat salah dicetak sebagai siap pakai. Harapan: status jujur ("terpasang, belum login"), bukan alamat tebakan.

```go
	Fetch   func(ctx context.Context, url, sha256hex, destDir string) (string, error)
	RS      rustdesk.Manager
}
type Options struct { AdoptExisting bool; ArtifactPath string }
type Result struct { Changed bool; Actions []string }
func Run(ctx context.Context, env Env, opts Options) (Result, error)
```
Subperintah `rc install [--config PATH] [--adopt-existing] [--archive PATH]` dan `rc uninstall [--keep-config]` merakit `Env` dari nilai nyata dan memanggil `install.Run`. Checksum salah → error dan `rc.yaml`/paket tidak berubah.
