# kendali 0.2.0 — Terminal: Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menghasilkan `kendali-term` sidecar yang menyajikan shell pengguna lewat browser (xterm.js) dengan auth token, idle timeout, dan rate limit, pada `bind: localhost` (tunnel desktop) atau `bind: tailnet` (termasuk Android).

**Architecture:** Binary Go terpisah `cmd/kendali-term`, disematkan aset web, PTY lewat `creack/pty` (Unix) / ConPTY (Windows), WebSocket untuk I/O. Auth token dari `rc.yaml`, dibandingkan constant-time, rate limit per IP, cookie sesi setelah auth pertama. Service systemd/Windows service berjalan sebagai pengguna login.

**Tech Stack:** Go 1.23, `github.com/creack/pty`, `github.com/UserExistsError/conpty`, `nhooyr.io/websocket`, `gopkg.in/yaml.v3`, xterm.js (embedded).

**Spec:** `docs/superpowers/specs/2026-10-31-kendali-0.2.0-terminal-design.md`

## Global Constraints

- Nol patch pada RustDesk; terminal tidak bergantung pada RustDesk kecuali untuk tunnel (desktop).
- `kendali-term` berjalan sebagai pengguna login, bukan root.
- Bind default `localhost`; `bind: tailnet` memerlukan konfirmasi eksplisit.
- Tidak ada port terbuka ke LAN/USB untuk terminal.
- Token 32 byte, constant-time, rate limit 5/menit/IP, lockout 15 menit setelah 10 kegagalan, idle 30m.
- Log tidak memuat token atau isi sesi.
- Coverage ≥80% (kecuali exec.go), `make verify` hijau, CodeGraph bersih.

## Review Focus

1. **Token di URL** — muncul di history/log browser; mitigasi cookie sesi HttpOnly setelah auth pertama.
2. **PTY sebagai pengguna login** — jangan eskalasi ke root; shell yang diluncurkan harus `SHELL`/`COMSPEC` pengguna.
3. **Rate limit bypass** — klien bisa memutar IP; batasi juga per token-global (lockout).
4. **Idle timeout** — sesi harus mati saat koneksi putus, tidak tertinggal zombie.
5. **Bind tailnet tanpa konfirmasi** — jangan buka port tailnet secara diam-diam.
